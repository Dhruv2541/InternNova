## Week 1: Core Java Fundamentals

> [!NOTE]
> **Week 1 status: Completed**. All six foundational tasks and verification outputs have been completed and verified.

The primary objective of Week 1 was establishing a solid foundation in core Java syntax, memory types, and runtime input processing.

### Key Topics & Implementations

- **Program Anatomy & Output**: Entry point structure, standard output streams (`System.out.println`).
- **Data Types & Variables**: Declaration and initialization of primitives (`int`, `double`, `float`, `char`, `boolean`) and `String`.
- **User Input Handling**: Interactive console input using `java.util.Scanner` and handling newline delimiter edge cases.
- **Arithmetic Engine**: Operations (`+`, `-`, `*`, `/`, `%`) with formatted output (`printf`) and division-by-zero checks.
- **Type Conversion**: In-depth practice with widening (implicit) and narrowing (explicit) type casting.
